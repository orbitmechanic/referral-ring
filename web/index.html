The ring turns in four moves

  1. 01

    Pull a code

    Write it down. It's held for you for 72 hours so nobody else gets handed the same one.

  2. 02

    Sign up at Cape with it

    Both of you get $20 off, per month, while you both stay subscribed. That's Cape's rule, not ours.

  3. 03

    Come back and register the claim

    The code's owner checks their own bill. When they see the credit land, they vouch for you — that's the lock.

  4. 04

    Hand your own code back

    Once you're confirmed, you add your code and how many referrals you still need. The ring turns again.

A code is never given to two people at once, and nobody can add a code until the person they used has confirmed the credit on their account. That's the whole trust model — no accounts, no passwords, just one private link per person.

Who's waiting right now

We deal the neediest first: a code needing four referrals is four times likelier to come out of the machine than one needing a single referral.

Why we can't email you a magic link

Cape hands out $20 a month forever. An email server that can be phished is a liability, so there isn't one. Your key lives in a URL, and the only way in is to have it. Bookmark it. Nobody here can reset it for you.
